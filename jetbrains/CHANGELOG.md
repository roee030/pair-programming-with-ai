# Changelog

Release notes for the JetBrains plugin. The newest version goes first; its bullet list becomes the
"What's new" section on JetBrains Marketplace.

## 0.1.0

- First preview for IntelliJ IDEA, WebStorm, PyCharm and the other JetBrains IDEs (2025.1 and newer).
- Plan first, then review every chunk (at most three files) in the native diff viewer before it is written.
- Each approved chunk is a single Undo step.
- Works with OpenAI, Anthropic, Gemini, OpenRouter or a local Ollama; API keys are kept in the IDE password safe.
- Sessions are saved per project and can be paused, resumed or retried.
